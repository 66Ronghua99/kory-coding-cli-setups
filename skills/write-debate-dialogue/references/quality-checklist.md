# 成稿质量清单

交付前逐项检查。任何 **阻断项** 失败都必须先修改成稿；不要把失败清单交给用户代为处理。

## 1. 来源忠实度（阻断项）

- [ ] 每个姓名、机构、日期、数字、单位和引用都能在源文中定位。
- [ ] 比例保留了分母，增减保留了比较基线，统计结果保留了样本和条件。
- [ ] “可能、相关、初步、在特定条件下”等限定词没有被升级为确定因果。
- [ ] 对话没有新增来源未给出的事实、案例、引用、动机或权威背书。
- [ ] 假设性追问仍然写成假设，没有伪装成事实。
- [ ] 源文矛盾、空缺或无法读取之处被明确保留，没有擅自补全。
- [ ] 若使用外部研究，用户确实要求了研究，且外部内容与源文内容被清楚区分。

## 2. 论证推进（阻断项）

- [ ] 开场两轮内出现中心争点。
- [ ] 至少四轮承担不同功能，如换基准、查证据、攻假设、给反例、压边界或回到决策。
- [ ] 相邻两轮没有只换措辞重复同一观点。
- [ ] 问题推动讨论进入下一层，而不是仅索取下一段信息。
- [ ] 最强可用反对意见得到正面回应，没有被改造成稻草人。
- [ ] 结尾明确落在共识、核心分歧、适用边界或未决问题之一。

## 3. 角色真实性（阻断项）

- [ ] 两个角色都有稳定、可描述的推理功能。
- [ ] 至少一方出现承认、修正、缩小范围或重新定义分歧。
- [ ] 没有角色被故意写笨，也没有一方只负责递话筒。
- [ ] 篇幅不对称来自证据负担，而不是作者偏爱。
- [ ] 冲突针对主张、证据和假设，不针对身份或人格。

## 4. 对话节奏

- [ ] 尖锐句较短，证据段较长，长短有变化。
- [ ] 连续长段落已按逻辑动作拆分，不按字数机械切割。
- [ ] 反问、感叹号、口头语和类比没有泛滥。
- [ ] 同一句式骨架没有反复出现。
- [ ] 去掉角色标签后，两个声音仍能通过关注点和句长大致区分。

## 5. 输出完整性（阻断项）

- [ ] 标题呈现真实张力，不是泛化主题名。
- [ ] 两个角色名易记，并能反映立场或功能。
- [ ] 正文形成完整论证弧，而非片段拼接。
- [ ] 原文存在的必要引用或免责声明仍在相关位置。
- [ ] 没有追加重复对话内容的空泛总结。
- [ ] 成稿符合用户指定的语言、受众、篇幅和强度；未指定时符合 skill 默认值。

## 6. 最终反事实检查

交付前问自己：

1. 如果删掉角色标签，这仍然是一条清晰、可验证的论证链吗？
2. 如果把强烈措辞全部删掉，冲突是否仍然成立？若不成立，说明张力是伪造的。
3. 如果原作者逐条核对事实，能否指出任何数字漂移、因果升级或观点歪曲？
4. 第二角色是在提出源文内部可支持的挑战，还是生成器为了热闹自行编了一个对手？

任一答案暴露问题时，返回成稿修正后再交付。
