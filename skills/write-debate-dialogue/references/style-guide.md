# 对谈风格参考

这份参考提炼自用户提供的双人财经口播形式，但规则适用于任何主题。借用它的结构张力，不复制其中的公司、数字、立场或攻击性用词。

## 1. 六个核心动作

### 1.1 共识击穿

先让推进者说出读者最容易接受的表面结论，再让拆解者指出真正的判断基准。

```text
推进者：增长了，不就说明策略有效吗？
拆解者：先别急。增长回答的是“有没有变多”，没有回答“是不是因为这项策略”。
```

第二句必须引入新的尺度、证据或逻辑问题，不能只写“你错了”。

### 1.2 功能不对称

推进者负责入口、直觉、疑问和情绪；拆解者负责证据、机制、计算和边界。两人篇幅无需平均。

短问题之后可以跟一个较长回答，但长回答内部只处理一个主要论证动作。需要进入下一层时，把转折留给下一轮。

### 1.3 问题升级

问题要改变讨论层级。常见升级链：

```text
发生了什么？
→ 这能证明什么？
→ 还依赖哪些假设？
→ 最强反例是什么？
→ 在什么条件下结论会失效？
→ 面对这些不确定性该如何判断？
```

避免“然后呢”“还有呢”式取号问题。

### 1.4 证据与口语交替

连续数字、定义或因果解释之后，用一句具体场景、类比或反问减轻负担。

```text
拆解者：样本只覆盖已经留存的用户，因此结果描述的是幸存者，不是所有新用户。
推进者：也就是说，我们拿留在船上的人证明这条船不会漏水？
```

类比只能解释源文已有逻辑，不得偷偷引入新事实。

### 1.5 角色发生变化

真实对谈应出现至少一种变化：

- 承认对方局部成立；
- 缩小原主张的范围；
- 从事实争议转向价值或决策争议；
- 发现双方使用了不同定义；
- 承认材料不足以裁决。

```text
推进者：那我收回“已经证明”。更准确地说，它只是一个值得继续验证的信号？
拆解者：对。分歧从“信不信”变成了“需要什么证据才能信”。
```

不要让一个角色从头到尾只负责挨打。

### 1.6 不强行和解

结尾应留下判断压力，而不是礼貌性总结。

可用四种收束：

- **共识**：双方确认了一个被证据支持的最小结论；
- **分歧**：双方事实一致，但风险偏好或价值排序不同；
- **边界**：结论只在明确条件下成立；
- **未决问题**：指出下一条真正能改变判断的证据。

## 2. 对话节奏

- 开场两轮内进入核心争点。
- 尖锐句宜短，证据句可长。
- 每 2—4 轮出现一次认知升级、承认或转向。
- 连续三个长段落会失去对话感；拆分逻辑层次，而不是按字数硬切。
- 感叹号、反问和口头语点到为止。张力主要来自观点受压，不来自标点。

## 3. 交锋句式的功能

这些句式只能在其功能真实存在时使用，不要机械套模板。

- **换基准**：“这个数字没错，但你拿错了比较对象。”
- **查因果**：“时间先后成立，不等于因果已经成立。”
- **攻假设**：“你的结论要成立，至少还得同时满足三件事。”
- **给最强反方**：“先替你的观点补上最强的一块证据。”
- **承认局部**：“这一点我同意；真正的分歧在后半句。”
- **压边界**：“在实验条件内成立，出了这个范围原文没有回答。”
- **回到决策**：“我们现在缺的不是态度，而是哪条证据会改变选择。”

同一篇中不要重复使用相同句式骨架。

## 4. 强度控制

### Low

冷静、精确、苏格拉底式。适合论文、政策、医疗和教学材料。

### Medium（默认）

直接反驳、短促反问、少量轻讽刺。适合公共博客和行业分析。

### High

加快轮次、缩短句子、强化口语压力。仍然禁止身份攻击、羞辱弱者、虚构动机或把不确定写成确定。

无论强度如何，证据标准完全相同。

## 5. 反模式

- 两人轮流朗读原文段落；
- 推进者永远问“为什么”，拆解者永远上课；
- 为了平衡而给证据薄弱的一方相同篇幅；
- 把作者最强观点改写成明显愚蠢的说法；
- 每轮先复述上一轮再回答；
- 用“其实”“本质上”“显然”制造并不存在的确定性；
- 结尾写“看来双方都有道理”；
- 用辱骂、阴谋动机或网络梗替代可检查的反驳。
